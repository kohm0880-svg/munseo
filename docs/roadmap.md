# Roadmap

## P0 — importer/editor 검증
- 다양한 실제 HWPX 실패 사례 수집
- charPr / paraPr 기본 스타일 복원
- 병합 표, 이미지 안정화
- 일반/양식 모드 UX 검증

## P1 — 레이아웃
- 정확한 줄 단위 pagination
- 표 행 단위 분할
- A4/B4/A3/Letter/사용자 지정
- 직접 여백 조절
- `정확히 N쪽` 최적화

## P2 — 포맷
- 자체 JSON 파일 import/export
- 원본 XML patch 방식 HWPX export
- PDF export 안정화
- binary HWP importer

## P3 — 클라우드
- 인증
- API 저장소 어댑터
- 링크 공유
- 버전 기록
- 폴더/작업공간

## P4 — 협업/앱
- 공동편집
- 댓글/멘션
- 데스크톱 앱 및 파일 연결
- 모바일 검토/간단 편집
- 작업공간 대화
